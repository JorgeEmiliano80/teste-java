# portfolio-api

API Java con Spring Boot para gestion de portfolio.

## Stack

- Java 21
- Spring Boot 3.5.x
- Maven
- PostgreSQL
- Spring Web
- Spring Data JPA
- Spring Validation
- Spring Security
- Springdoc OpenAPI
- JUnit, Mockito y JaCoCo

## PostgreSQL

```bash
docker-compose up -d
```

## Ejecutar la app

```bash
mvn spring-boot:run
```

## Swagger

```text
http://localhost:8080/swagger-ui.html
```
